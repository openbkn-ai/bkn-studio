# 原生证据链与执行链组件

`EvidenceChainPanels` 接收 `evidence-chain.types.ts` 中的内部只读模型，不发起请求。由宿主读取固定版本投影后传入；这里不定义 HTTP 契约。

- 两个图只绘制上游提供的边，不通过时间、排列或相同值补关系。
- 答案锚点仅接受 `checked`、`located`，并检查 Unicode 码点范围与原文 exact。`candidate` 不生成链接。
- 点击结论只展开显式上游关联；循环引用可终止遍历。未绑定、依据缺失、仅定位返回值分别显示。
- 没有结构化结论绑定时，`claims` 留空，事实图可照常展示。不能把事实自动标为答案依据。
- `checked` 仅表示指定的有限计算已核验，不表示整个答案语义正确。
- 节点技术信息仅在用户打开详情后折叠提供。切换 interaction/revision 重置选择。

## 本地真实样本预览

运行 Vite 开发服务器，打开 `/studio/evidence-chain-preview.html`。选择服务端生成、符合内部模型的本地 JSON（8 MiB 以内；单图 500 节点、1000 边以内）。文件不上传，不复制到 public；入口只在 DEV 渲染，不进入正式路由或生产构建入口。

预览不负责 Trace 转换、事实提取或绑定推断。真实业务文件保留在仓库外。组件测试中的合成输入仅测试 UI 契约。

## 高保真原型对照（2026-09-10）

依据 workspace 的 `docs/prototypes/evidence-chain-panel` 最新双 Panel，以及 `answer-evidence-reader`、`report-object-reader`：

| 原型交互与表达 | 原生实现 | 证据边界 |
| --- | --- | --- |
| 浅灰工作区、白色卡片、蓝色焦点、柔和点阵画布 | CSS Module，复用语义主题变量，支持窄屏 | 不把原型合成数据搬入产品 |
| 对象与结论目录 | `claim.objectLabel` 显式分组、选中态和结论值 | 无绑定则显示事实对象目录，不生成假结论 |
| 正文多个独立链接，当前项深色 | Unicode exact 锚点和 `aria-pressed` | candidate/失效范围不生成链接 |
| 结论—字段—对象/计算—来源分栏 | `layoutChain` 根据业务角色稳定分栏 | 排列不决定边、调用顺序或因果 |
| 条件—处理—结果执行视图 | input / process / output 角色分栏 | 未记录输入或内部步骤不补画 |
| 点击连线看语义 | SVG 键盘可操作连线，展示说明、角色与默认折叠技术详情 | 对象归属、主键、上下文不当作计算输入 |
| 展开主键及上下文 | key/context 边默认隐藏；业务对象仍默认显示 | 展开不提升依据状态 |
| 来源下钻、在执行链中查看、返回结论 | `executionNodeId` 确认引用双向导航 | 缺少显式引用就不提供导航入口 |
| 大图与移动端 | 图内滚动，页面布局自适应，文字截断可点详情 | 不实现自动分页或新的传输契约 |

新增验证：语义分栏与输入数组顺序无关，30 个混合业务角色节点无重叠，输入/函数/输出分列；边详情与元数据开关、来源执行往返、无引用时不导航。原型没有的语义不从样式或相同数值推断。

## B2–B5 最小可用修复（本地组件范围）

- **无对象的函数/指标返回**：除业务对象目录外，按已有 source 节点身份提供“计算 / 指标返回”目录。同名函数、同值字段、不同调用均不合并；只读取明确的 source → field 数值引用。未增加业务对象或答案绑定。
- **局部图与子图关系**：对象视图保留与该对象明确相连的 relation 节点和另一端对象；字段聚焦只显示其明确归属与来源。来源分组也支持字段聚焦、返回本次来源全部字段，不沿共享来源引出其他调用或对象。
- **执行导航**：来源/字段自带精确 executionNodeId 时才跳转，记住原事实以便返回。执行默认显示选中处理及其直接记录关联，通过业务名称选择其他处理；序号仅供区分选项，不声明顺序。原始技术身份仍在默认折叠的详情中。
- **业务文案与缺口**：补齐中英文 relation 类型；空字符串和纯空白答案均显示“未记录答案正文”。函数结果定位不宣称内部计算解释完整。

以上由 pure scope 与组件交互测试验证。正式 CurrentExplanationPanel、HTTP 服务、BusinessProvenanceScene、共享后端浏览器验收由主任务负责；本修复不宣称这些集成验收已完成。

执行选择器以业务操作优先，其他所有已记录节点也可作为局部中心选择。不能仅用节点是否已出现在某个操作的一跳图中判定是否需要入口：两个结果节点之间的真实桥接边仍需可达。界面统一称“其他记录”，不把已有关联的记录误标为孤立。
