# 业务溯源分析字号设计

## 目标

将业务溯源分析详情页收敛为与日志检索一致的紧凑阅读密度，同时保留会话、轮次和调用卡之间的最小层级。

## 已确认的字号

- 会话标题：18px。
- 当前轮次标题、调用卡标题：16px。
- 输入/输出正文、调用条件、结果和其他内容：14px。
- 辅助信息保留 12px。

## 范围

仅修改 `BusinessProvenanceScene.module.css` 中分析详情的排版声明；不修改接口、数据、交互、时间线结构或列表页。

## 验收

在本机业务溯源分析页中，分析详情不再出现 30px、21px、18px 或 16px 的内容字号；会话标题、轮次与调用卡仍可通过字号层级快速辨认。
