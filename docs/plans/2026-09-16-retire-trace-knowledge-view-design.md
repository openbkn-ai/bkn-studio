# 业务溯源知识网络视图退役设计

## 目标

从业务溯源分析工作区移除“知识网络视图”这一并列主视图，保留时间链、证据链和执行链三个能直接回答业务问题的入口。

## 决策

采用完整 UI 退役，而不是隐藏入口或改造成新的抽屉。当前知识网络视图只是从已有 Interaction 投影中按网络汇总被观测的元素，并把元素反查到相关调用；它没有独立路由、服务端资源、持久化状态或公开契约。时间链的调用详情已经提供知识网络、业务对象、关系/指标和资源映射；证据链提供结论到正式本体元素的关联。因此保留并列入口会增加认知负担，却不提供不可替代的业务判断。

## 保留范围

- 保留 Interaction 投影、操作元素、上下文关系、知识网络 ID 和调用范围解析。
- 保留时间链调用详情中的知识网络、业务对象、关系/行动/指标、资源和定位方式。
- 保留证据链和执行链的读取、切换与深链行为。
- 不修改 BKN Trace 后端、MCP/SDK 契约、Trace 历史记录或数据迁移。

## 删除范围

- 移除 `knowledge` 视图枚举值及其分段入口。
- 移除仅服务于该页面的元素分组、选择状态、关联调用检查器和页面分支。
- 移除仅被这些组件引用的文案、测试断言和样式。

## 兼容与失败边界

视图选择只在组件内存中保存，没有可访问的 URL 参数或公共路由。因此不存在旧书签或外部链接的兼容负担。退役不影响任一历史 Interaction 的投影读取；投影不可用时仍保持既有 Markdown 降级行为。将来若需要“本体覆盖分析”或跨会话本体治理，应以独立产品能力重新设计，而不能恢复这个交互轮次内的辅助清单。

## 验收

- 工作区只显示时间链、证据链和执行链。
- 时间链详情继续显示调用关联知识网络和业务对象范围。
- 证据链与执行链仍可按选中 Interaction 正确加载。
- Studio 不再保留知识网络视图专属状态、组件分支、测试或样式引用。
