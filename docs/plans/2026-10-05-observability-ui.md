# 可观测性页面局部修订设计与实施计划

**Goal:** 修复业务溯源详情刷新、轮次布局及筛选语义，改善操作日志详情可读性。

**Architecture:** 只调整 Studio 模块，复用现有查询和组件；不改变后台状态、接口、精确匹配规则，不增加轮询。用户已确认局部修订方案。

**Tech Stack:** React、Ant Design、CSS Modules、Vitest。

## 设计边界

- 详情刷新仅重新读取当前会话轮次、当前轮次事实和已保存分析，不请求会话列表；保留选中轮次和筛选。正在生成分析时禁用刷新，避免打断分析。
- 单轮卡片按内容高度排列，保留滚动。默认四项筛选不新增面板，修正六个控件的网格列。
- Trace 筛选标为根服务、根调用，提示精确匹配；后台参数保持原样。
- 日志继续以 outcome 展示结果。事实区已知枚举增加中文映射，未知值保留；技术标识保留原值、支持复制和完整值提示。
- 日志详情适度拓宽并在窄屏收敛，短字段可双列；已有摘要和折叠保持，不新建组件框架。
