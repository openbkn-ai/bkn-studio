# 可观测性页面白色底板设计

## 目标

让“业务溯源”和“Trace 分析”与“日志检索”保持一致的页面层级：先呈现完整白色页面底板，再在底板内组织标题、筛选区、列表与详情内容。

## 设计决策

- 两个页面根容器统一使用白色背景、浅色边框、24px 内边距和完整最小高度。
- 保留现有标题、卡片、表格、时间链、知识网络视图与详情面板，不改变数据和交互。
- 保留内部卡片的浅边框与轻阴影，使其在白色底板上仍有清晰层级，不形成“白色内容直接嵌入白底”的扁平效果。
- 中小屏仅收紧根容器内边距，不新增断点或布局结构。
- 不抽取公共组件；当前改动仅涉及两个页面，避免样式耦合和过度设计。

## 验收

- 业务会话列表、业务溯源详情、Trace 列表与 Trace 详情均位于统一白色底板内。
- 页面标题与首个内容区之间留白自然，内部卡片边界仍清晰。
- 原有交互与响应式布局不受影响。
