# BKN Trace 0.1.4 Unified High-Fidelity Prototype Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将现有业务溯源高保真原型扩展为同时覆盖企业业务溯源和社区 Trace 分析的统一交互原型。

**Architecture:** 保留一个自包含 HTML 和现有 OpenBKN Studio 壳，通过左侧菜单切换两个独立页面状态。共享一个两行长文本组件和全文浮层，不共享业务解析状态。

**Tech Stack:** HTML、CSS、原生 JavaScript、Vitest 静态合同测试。
